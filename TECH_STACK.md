# Indian Sign Language (ISL) Detection and Translation System: Tech Stack

## Architectural Overview

The ISL Detection and Translation System is an enterprise-grade, real-time computer vision and natural language pipeline designed to recognize static manual gestures, capture dynamic movement-based signs via temporal modeling, segment continuous signing streams, and translate Indian Sign Language (ISL) gloss sequences into grammatically sound English with auditory text-to-speech feedback.

## Architectural Rationale: Gesture Recognition vs. True ISL Translation

A fundamental engineering principle of this system is respecting the boundary between **gesture classification** and **language translation**:

1. **Sign Classification**: Maps visual landmark patterns in a bounded temporal window to discrete gloss labels (e.g., `[ME]`, `[TEACHER]`, `[MEET]`).
2. **Sign Segmentation**: Uses kinetic energy, hand velocity thresholds, and debouncing to isolate individual signs within a continuous video stream without requiring artificial pauses.
3. **Translation Engine**: Maps the segmented gloss sequence (`ME TEACHER MEET`) to grammatical natural English (`I am meeting the teacher`) via syntactic restructuring, copula insertion (`am`), pronoun resolution (`ME` -> `I`), and morphological inflections.
4. **Speech Synthesis**: Converts the synthesized natural English into vocal speech output.
